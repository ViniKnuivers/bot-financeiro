# secrets/

Coloque aqui o arquivo JSON da conta de serviço do Google, com o nome
`google-service-account.json` (veja "Planilha Google" no README do projeto).

Tudo nesta pasta, exceto este arquivo, fica fora do git e da imagem Docker: a chave dá
acesso de escrita às planilhas compartilhadas com a conta de serviço.
